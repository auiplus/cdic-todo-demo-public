# To-do ภาษาไทย

เว็บแอปจัดการรายการสิ่งที่ต้องทำแบบหน้าเดียว ใช้ HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งหรือ build

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์

## ความสามารถ

- เพิ่มงาน ทำเครื่องหมายว่าเสร็จแล้ว และลบงาน
- กรองรายการทั้งหมด งานที่ยังไม่เสร็จ และงานที่เสร็จแล้ว
- ล้างงานที่เสร็จแล้ว หรือล้างรายการทั้งหมดหลังยืนยัน
- บันทึกรายการใน `localStorage` ของเบราว์เซอร์เครื่องนั้น

ข้อมูลจะอยู่ในเบราว์เซอร์ที่ใช้เปิดเว็บนี้เท่านั้น ยังไม่มี backend หรือการ sync ข้ามอุปกรณ์
